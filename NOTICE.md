# Atribución de terceros

## Dataset de ejercicios

Este proyecto usa datos e imágenes descargados por `npm run setup:dataset`
desde el repositorio [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)
a la carpeta local `data/` (no versionada en este repositorio).

- El código, el JSON de ejercicios y el schema de ese repositorio están bajo
  licencia MIT.
- Las imágenes y GIFs de las carpetas `images/` y `videos/` son propiedad de
  **Gym Visual** (https://gymvisual.com) y se redistribuyen únicamente "con
  permiso" en el repositorio origen, en tamaño reducido (180×180 px), con la
  atribución obligatoria:

  > © Gym Visual — https://gymvisual.com/

- Ese material **no tiene licencia libre de redistribución más allá** del
  repositorio origen. Este proyecto lo usa solo como fuente de datos local
  para uso personal; no lo redistribuye ni lo publica.

Si vas a distribuir este proyecto públicamente (más allá de uso personal en
tu propia máquina), revisa los términos de Gym Visual antes de incluir o
servir esas imágenes.
